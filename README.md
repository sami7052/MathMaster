#🧮 MathMaster

MathMaster is a Python-based mathematics quiz application that helps students practice mathematics and track their learning progress.

##🚀 Features

- 🎚️ Easy, Medium, and Hard difficulty levels
- ➕ Addition & Subtraction
- ✖️ Multiplication
- 🔢 Powers
- 🎲 Mixed Challenge
- 🔄 Second-chance answers
- 📊 Statistics and performance tracking
- 🏆 Leaderboard
- 🏅 Achievement badges
- 📈 Progress history
- 💾 Automatic data saving
- 📄 Automatic progress reports
- 🛡️ Input validation

##🛠️ Built With

- Python
- Random number generation
- JSON data storage
- File handling
- Functions
- Loops
- Conditional statements
- Input validation

##📚 What I Learned

While building MathMaster, I practiced Python programming, problem solving, data storage, input validation, and organizing a larger program into different functions.

##🎯 Purpose

I created MathMaster as a practical project to strengthen my Python skills while building a useful mathematics practice application.
